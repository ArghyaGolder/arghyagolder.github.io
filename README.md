# Arghya Golder — Neobrutalism Portfolio

A responsive React + Vite + Tailwind CSS portfolio using a cream, lime and pastel neobrutalism visual system.

## Run locally

1. Install Node.js (20+ recommended).
2. Open this folder in VS Code / terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

- Add your resume PDF at `public/resume.pdf`. Until then, the resume button shows a friendly reminder.
- Confirm the email address in `src/components/Contact.jsx`.
- Confirm project descriptions accurately reflect your contribution.
- Confirm the social profile URLs in `src/components/Footer.jsx`.
- Deploy the folder to Vercel or Netlify.

## Sections

Hero, About, Skills (two categories / 23 skills), Projects (three live sites plus collaboration CTA), Services, Contact, Footer.
